### PF-068 · An app outside the registry is found by its window title, so "did not open" is not claimed for a running app
- **Files:** `core/live_app_state.py`, `actions/open_app.py`, `actions/window_control.py`
- **Rule:** The process name(s) checked for ANY app come from `actions.open_app.known_exe_names` (the launcher's own registry / Start Menu shortcut resolution; updaters/bootstrappers excluded; only found answers cached) unioned in `_identity`, never from the spoken name alone. Then `collect_live_state` looks for the guessed exe; if no process matches it also takes the process names that own a visible window whose title contains every word of the app name (`_names_from_window_titles`, only when the guessed exe found nothing) and re-reads the processes. Also `_names_from_process_stems` (6+ letters, version numbers ignored: "Premiere Pro 2026" finds `Adobe Premiere Pro.exe`). The registry exe for Premiere is `Adobe Premiere Pro.exe` in BOTH `actions/open_app.py` and `actions/window_control.py` (it was `Premiere.exe`, which never exists). Never weakens the check for registered apps; a title match needs 4+ letters.
- **Why:** Live 2026-11-20 15:08: "open Neat Download Manager" opened it (process `NeatDM.exe`, window "Neat Download Manager 1.4") but Era said "did not open: no Neat download manager process is running", because the verifier only looked for `neat download manager.exe`.
- **Guards:** `tools/test_inactivity_window.py::test_an_unregistered_app_is_found_by_its_window_title`, `tools/test_inactivity_window.py::test_premiere_pro_uses_its_real_exe_and_is_found_by_process_stem`, `tools/test_inactivity_window.py::test_any_app_uses_the_exe_its_launcher_resolves_not_a_guess`
- **Since:** 2026-11-20 · Claude · Windows tests; real window/process read checked against the running NeatDM; a live "open Neat Download Manager" by voice not yet tried. Apps that start in the tray with no titled window can still read as not running.
